# Field test report R0 to R4, 2026-10-19

Tester: Claude (automated, through UI Automation, the bridge and scripts). Guide: `field-test-R0-R4.md`.

**Environment:** Windows 11 Pro 10.0.26300, one monitor 1920x1080 at 100%, default browser Brave, rune-infer 0.6.0 (one loaded model at a time), `gemma-4-12b-it`, commit `528676c` on `develop`, **dev build** (`target/debug`), app started from Git Bash. No microphone voice (speakers into the mic only).

**Read this first.** On the original code **every built-in task freezes the app** (BUG-01). To test anything else I applied three small local fixes, left uncommitted in the working tree (`local-fixes.diff` next to this file): BUG-01 in `agent/mod.rs` and `bridge/mcp.rs`, and BUG-03 in `analysis/run.rs`. All results below are with those fixes unless the row says otherwise.
