## 3. Bugs I found myself while fixing

- Analysis picture: a **Retry** after an error asked whatever was typed in the box instead of the question that failed. Fixed.
- A fresh analysis opened its window **before** taking the screenshot. The window is capture-excluded, but the first frame should not depend on that, so the order is reversed.
- A task could be started **while** an analysis was capturing; it is now refused (the mirror of the analysis refusal).
- The two wire-name bugs under BUG-16.

## 4. DECIDE items and the default taken

- BUG-06: keep fast checks, **off by default**.
- BUG-08: a spoken task waits **2 s** on the pill and can be cancelled with Stop. There is no Cancel _button_: Stop is the hotkey or the tray menu (the orb offers Stop only while a task runs, which is after the delay).
- BUG-15: boxes **off by default**.
- Not asked, but yours: lower `RISKY` (0.8) so a "high" with probability 0.587 is escalated? I left it.
