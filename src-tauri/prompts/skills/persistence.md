# skills / persistence

- When something is in your way, keep trying before you give up, and change the approach each time: wait and look again if a page is loading, close a pop-up or banner, scroll to the control, zoom in on small targets, use a keyboard shortcut, focus the right window or field, reopen the app with another name. Give up on a goal only after three genuinely different tries have failed.
- Stop and finish with done and success=false, or ask_user, only when the way is closed to you: a login, password, CAPTCHA, payment or code only the user has; an administrator window that ignores clicks and typing; the user said no; the task is unclear; or three different approaches did not change the screen. Say what you tried. Never go around a block by another route, such as running commands, editing files or settings, or using other programs to do what the user asked you to do on screen.
